# Неделя 4: службы

Старт — 03.11.2026, слово владельца: «Ок жду» (после «Неделю 4 начну по
вашему слову»). Цель из дорожной карты (`06-roadmap.md` студии, часть А) и
разделов 02-architecture «Службы», «Мониторинг и сторож», «Удалённая
поддержка».

**Проверяемый результат недели**: тесты в Actions — неподписанный
контейнер не стартует; убитая служба поднимается сама; кнопка поддержки
выключает канал.

## Задачи

| № | Что | Готово, когда |
|---|---|---|
| 1 | Podman + quadlet, политика подписи контейнеров (`/etc/containers/policy.json`: всё — только с нашей sigstore-подписью, ключ в `/usr`) | тест: подписанный образ из тестового реестра стартует как служба quadlet; неподписанный — не скачивается |
| 2 | Сторож на systemd: `Restart=`, `WatchdogSec=`, проверка здоровья; три неудачи подряд — строка «позвать человека» | тест: убитая служба поднимается; служба, которая падает всегда, после 3 попыток помечена |
| 3 | PostgreSQL и Caddy — подписанные контейнеры под quadlet, данные в `/var/lib/devuz` | тест: Caddy отвечает на `https://` своим сертификатом, PostgreSQL принимает запрос, обе переживают перезагрузку |
| 4 | Канал поддержки: клиент Tailscale (контейнер) к своему тестовому Headscale на раннере; кнопка `devuz-support on/off` | тест: вкл — коробка видна в Headscale; выкл — клиент остановлен, коробка недоступна |
| 5 | Отчёт `docs/week-04.md` | файл в `main` |

## Решения на старте

- **Всё, что не система, — контейнеры с нашей подписью.** В Debian 13 нет
  Tailscale и Headscale; PostgreSQL и Caddy в пакетах есть, но им нужен
  изменяемый `/etc` и данные при сборке — контейнеры проще и обновляются
  отдельно от системы (`podman auto-update`, неделя 8).
- **Подпись — sigstore (cosign), ключ тестовый, на лету в Actions**, как
  ключи Secure Boot и GPG. Открытый ключ кладётся в `/usr` через
  `--extra-tree`; закрытого в репозитории нет.
- **Тестовый реестр — на раннере** (`registry:2`), гость видит его как
  `10.0.2.2:5000`; раннеру добавляем тот же адрес на `lo`, чтобы подпись
  была на тот же адрес образа. Боевой реестр — открытый вопрос владельцу.
- cosign — версии 2.4 (подписи тегами `.sig`, их читает Podman 5.4 из
  Debian 13; формат cosign 3 он не понимает).

## Риски

| Риск | Что делаем |
|---|---|
| Docker Hub ограничивает скачивания в Actions | базовые образы берём с `mirror.gcr.io` |
| Политика в `/etc` — её может поменять root на коробке | как и весь `/etc`; root на коробке — только мы через канал поддержки. Записать в отчёт |
| Tailscale в контейнере требует `/dev/net/tun` и `CAP_NET_ADMIN` | проверяем первым делом в задаче 4; запасной путь — userspace-сеть Tailscale |
